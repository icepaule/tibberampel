Tibber Ampel

Eine physische LED-Ampel, die den aktuellen Tibber-Strompreis live über drei LEDs anzeigt: Grün für günstig, Gelb für normal, Rot für teuer.

ESP8266 · Tasmota · Home Assistant · Node-RED
Überblick Architektur Tech-Stack Quickstart

Überblick

Die Tibber Ampel ist ein kleines Smart-Home-Gadget auf Basis eines ESP8266 und eines dreifarbigen LED-Ampel-Moduls. Home Assistant berechnet aus dem aktuellen Tibber-Strompreis ein Preis-Level (günstig / normal / teuer), ein Node-RED-Flow übersetzt dieses Level in MQTT-Befehle, und die Tasmota-Firmware auf dem ESP8266 schaltet die passende LED. So sieht man auf einen Blick, ob sich gerade ein Stromverbraucher lohnt.

Drei-Farben-Anzeige

Rot, Gelb, Grün auf einem fertigen Ampel-PCB – einfach abzulesen, keine App nötig.

Schwellwert-basiert

Preis-Level relativ zum Tagesdurchschnitt (unter 70 % / bis 130 % / darüber), anpassbar im Home-Assistant-Sensor.

Saubere Trennung

Die Logik läuft in Home Assistant und Node-RED, der ESP8266 übernimmt nur das reine Schalten der LEDs via MQTT.

Erweiterbar

Weitere Ampeln lassen sich per eigenem MQTT-Topic und dupliziertem Flow ergänzen, z. B. für einen anderen Raum.

Architektur

Der Datenfluss beginnt in der Tibber-Cloud und endet an drei LEDs. Home Assistant und Node-RED übernehmen die gesamte Entscheidungslogik, MQTT verbindet die Smart-Home-Ebene mit der Firmware auf dem Mikrocontroller.

Ein Template-Sensor in Home Assistant berechnet aus dem Tibber-Preis das Level günstig / normal / teuer. Der Node-RED-Flow reagiert auf Statusänderungen dieses Sensors, mappt sie per Function-Node auf drei Ausgänge und sendet darüber MQTT-Befehle an die Tasmota-Topics cmnd/tibber-ampel/POWER1..3. Die Tasmota-Firmware schaltet dann direkt die entsprechende LED. Alternativ existiert dieselbe Logik auch als reine Home-Assistant-Automation ohne Node-RED.

Quickstart

Kurzfassung der Einrichtung – Details stehen im Repo-README.

# Repo klonen
git clone https://github.com/icepaule/tibberampel.git
cd tibberampel

# 1. Tasmota auf den ESP8266 flashen
esptool.py -p /dev/ttyUSB0 erase_flash
esptool.py -p /dev/ttyUSB0 write_flash -fs 4MB -fm dout 0x0 tasmota.bin.gz

# 2. Tasmota konfigurieren (Web-UI oder Serial-Konsole)
Backlog Hostname Tibber-Ampel-01; Module 0; Gpio12 224; Gpio13 225; Gpio15 226; Topic tibber-ampel

# 3. Node-RED Flow importieren
# Home Assistant > Node-RED > Import > Inhalt von nodered/tibber_ampel_flow.json einfügen, Deploy klicken

Voraussetzung ist ein Template-Sensor sensor.tibber_preis_status in Home Assistant (Beispiel in homeassistant/) sowie ein MQTT-Broker, mit dem sowohl Node-RED als auch der ESP8266 verbunden sind.
